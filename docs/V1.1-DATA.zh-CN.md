- 作者目标清空，未配置目标显示 --，进度条不假定完成度。没有上期记录时，不生成改善量。

## 后续更新

scripts/import_excel.py 接受任何符合现有英文表头的 XLSX 路径，不绑定某个云盘或唯一样本。根目录 Running_Log_EN.xlsx 是构建时默认读取的快照。

1. 可在本地或 Drive 编辑 Excel，保留历史 Actual 行和稳定的 Record ID。
2. 将更新后的 XLSX 上传覆盖仓库根目录同名文件。
3. GitHub Pages 工作流自动验证、转换并发布。无效数据使构建失败，上一次成功的网站继续保留。

本地转换：python scripts/import_excel.py Running_Log_EN.xlsx。依赖 openpyxl==3.1.5。

生成 src/static/activities.json 和 src/static/data-source.json。在线构建使用该次工作流生成的文件；提交中的 JSON 是最近手动导入的快照。

## Drive 自动同步

私有文件链接不会自动给 GitHub Actions 授予访问权。本次经已连接的 Drive 账户导入一次，保留私有权限和源文件。上传 GitHub 后的自动转换发布已配置；保存 Drive 文件后的无人值守同步还需要运行时授权。
